## 2. Interactive States & Micro-interactions

1. **Button Hover:** Transform scale `1.02`, subtle box-shadow expansion, transition `duration-200`.
2. **Focus-Visible:** 2px solid primary accent outline, 2px offset (WCAG 2.1 accessible).
3. **Card Elevation:** Subtle border with hover elevation (`shadow-md` $\to$ `shadow-xl`).
4. **Active Nav Link:** Bottom amber underline with brand text tint.

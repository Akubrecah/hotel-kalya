# DOC-038: 30-Day Post-Launch Warranty & Bug-Fix Policy

**Document ID:** `DOC-038`

**Status:** `ACTIVE WARRANTY`  
**Warranty Period:** `30 Calendar Days from Go-Live`  

---

## 1. Warranty Coverage

### Covered Under Warranty (Zero Additional Cost):
- Deficiencies, defects, or crashes where platform functionality deviates from approved requirements (`DOC-010`).
- Responsive layout bugs discovered on supported mobile and desktop browsers.
- API route handler exceptions resulting from code defects.

### Excluded from Warranty (Billed Separately):
- New page additions, new payment gateways, or feature extensions.
- Revisions to previously approved copywriting, pricing, or photography.
- Failures caused by client modification of source code or hosting settings.
- Third-party outages (Safaricom Daraja network downtime, Google Maps outages).

---

## 2. Response Time Service Levels (SLA)

- **Critical Defects (P0):** Acknowledgment within 2 hours; resolution target within 12 hours.
- **High Defects (P1):** Acknowledgment within 4 hours; resolution target within 24 hours.
- **Medium/Low Defects (P2/P3):** Resolution within 3 to 5 business days.

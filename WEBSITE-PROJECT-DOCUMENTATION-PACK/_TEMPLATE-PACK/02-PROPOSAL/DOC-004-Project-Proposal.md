## 3. Proposed Strategic Solution

We propose a production-grade web application built with **Next.js (App Router), TypeScript, and Tailwind CSS**:

1. **Multi-Page Architecture:** Dedicated canonical pages with zero long-scroll single-page compromises.
2. **Interactive Catalog & Booking Engine:** Fast client-side filtering, dates selection, and direct reservation triggers.
3. **Local Payment Gateway:** Seamless integration with M-Pesa STK Push and card/EFT payment methods.
4. **Administrative Console:** Real-time dashboard for front-desk and operations management.
5. **SEO & Performance Optimization:** Sub-second load times, Schema.org structured data, and 100% Core Web Vitals optimization.

## 5. Technology Stack & Architecture

- **Frontend:** Next.js (App Router, Server & Client Components)
- **Styling:** Tailwind CSS with Custom Brand Tokens & Mobile Off-Canvas Drawer
- **Language:** TypeScript (Strict Type Safety)
- **Backend Handlers:** Type-Safe Next.js Route Handlers (`/api/*`)
- **Hosting & Edge Delivery:** Vercel Global Edge Network / Cloudflare CDN
- **Security:** CSRF Protection, Kenya Data Protection Act Compliance, Sanitized Form Payloads

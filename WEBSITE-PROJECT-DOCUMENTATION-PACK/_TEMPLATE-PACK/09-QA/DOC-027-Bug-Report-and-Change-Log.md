## 1. Defect Classification System

- **P0 - Blocker:** System crash, build failure, security breach, or blocked core transaction.
- **P1 - Critical:** Major broken functionality with no viable workaround.
- **P2 - High:** Functional defect with an available manual workaround.
- **P3 - Medium:** Cosmetic, typo, minor spacing, or visual glitch.
- **P4 - Low:** Trivial suggestion or enhancement request.
